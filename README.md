# 🀄 넷마작 — 브라우저 온라인 리치마작

▶ **플레이: https://yayoflake.github.io/akdang-mahjong/**

설치 없이 브라우저에서 바로 즐기는 온라인 4인 리치마작입니다.
별도의 게임 서버 없이 방장의 브라우저가 탁자 역할을 하고,
참가자들은 P2P(WebRTC)로 연결되어 대국합니다.

## 게임 방법

1. **방 만들기** — 닉네임과 대국 길이(동풍전/반장전)를 정하고 방을 만들면
   6자리 방 코드가 생성됩니다.
2. **참가** — 친구는 방 코드 또는 초대 링크로 같은 페이지에서 참가합니다.
3. 사람이 부족하면 방장이 **🤖 AI 추가**로 빈 자리를 채웁니다.
   네 자리가 모두 차면 대국을 시작할 수 있습니다.
   (AI는 쯔모기리만 합니다 — 뽑은 패를 그대로 버리며, 울지도 화료하지도 않습니다)
4. 대국 중 참가자의 접속이 끊겨도 그 자리를 AI가 이어받아 대국은 계속됩니다.

**조작**: 버릴 패를 **두 번 클릭**(선택 → 확정)합니다.
론/퐁/치/깡/리치 등은 상황에 따라 나타나는 버튼으로 선택합니다.

## 채용 룰

천봉/작혼 계열의 표준 4인 리치마작 룰을 따릅니다.

- 반장전(동·남) 또는 동풍전, 시작 25,000점, 순위 우마 +20/+10/−10/−20
- 적도라 3장(5만·5통·5삭 각 1장), 쿠이탕 허용, 일발·우라도라·깡도라·깡우라 있음
- 더블론 허용(트리플론은 유국), 도중유국 있음(구종구패·사풍연타·4인 리치·사개깡), 나가시 만관 있음
- 토비(0점 미만) 종료, 오라스 1위 어가리야메, 동점 시 연장전(서든데스)
- 역만 책임지불(파오) 있음, 헤아림 역만 있음

## 개발

```bash
npm install   # 의존성 설치
npm run build # src/ → dist/app.js 번들
npm test      # 헤드리스 통합 테스트 (AI 수백 대국 시뮬레이션)
```

진행·역·점수 계산은 [電脳麻将(@kobalab/majiang-core)](https://github.com/kobalab/majiang-core) 엔진을 사용합니다.
